# gingi-melts-from-sun

This repository contains two independent apps:

- **AlcoSmart** (repo root: `index.html`, `welcome.html`, `inventory.html`,
  `board.html`, `users.html`, ...) - a Hebrew/RTL wine-store admin demo.
  Static HTML/CSS/JS, no backend.

- **[Home Inventory & Shopping List](home-inventory/README.md)**
  (`home-inventory/`) - a household inventory + shopping list app with a
  Node/Express backend, a web UI, and an Alexa voice skill. See
  `home-inventory/README.md` to get started.
